# Use a board-first contextual portrait interface

The Mission interface will reserve most of the portrait screen for the fully visible Arena. A compact top bar holds Lives, wave progress, Field Credits, pause, and speed. Planning presents a small next-wave action near the board's lower edge, while a contextual bottom sheet serves the selected tower, empty tile, Wave Briefing, or creep inspection. Opening a sheet must not permanently resize or displace the Arena, and primary actions stay in thumb reach.

Selecting a Mission Node opens one expandable Mission Brief containing the Threat Forecast, active entrances, Arena and Waypoint preview, best Stars and Mastery status, deterministic rewards, Loadout, and Deploy action. Loadout editing expands in context and returns to the same sheet.
