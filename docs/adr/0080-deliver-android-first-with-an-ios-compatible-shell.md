# Deliver Android first with an iOS-compatible shell

If Pixi passes the four-week gate, v2 will use a portrait-locked native mobile shell such as Capacitor. Android internal and closed testing comes first, followed by TestFlight after touch controls and performance stabilize. Web builds remain available for fast development and stakeholder previews, but desktop browser behavior does not determine product UX or performance budgets.

If Pixi fails the agreed gate, Godot replaces the presentation and delivery stack before substantial World content is produced.
