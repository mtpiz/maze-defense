# Start v2 with an installable Benchmark Build

The first implementation deliverable after design synthesis will be a four-week installable Android Benchmark Build rather than a broad feature scaffold. It contains one portrait Arena, Foundation construction and ordered routing, representative Rail, Arc, Siege, and Gravity behavior, Drones, Carapaces, Gliders, a 100-creep Broodling stress wave, a real contextual HUD, touch input, audio, haptics, compact damage text, accessibility controls, deterministic tests, and device instrumentation.

The Gate concludes with a frame-time, memory, thermal, and battery report; side-by-side visual assessment against the selected Infinitode, Geometry Wars, and The Tower qualities; and a written Pixi-versus-Godot decision. Full World authoring does not begin until this decision is made.
