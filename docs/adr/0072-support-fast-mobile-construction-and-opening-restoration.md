# Support fast mobile construction and opening restoration

Foundation construction will preserve the live prototype's direct placement model while adapting it for portrait touch input. Tapping places one Foundation, dragging paints Foundations across multiple cells, and the Route Preview recalculates continuously. Invalid placements are rejected with a visible explanation. Before Wave One, undo and removal remain lossless; later build phases use the established refund rules.

Each Mission automatically saves the most recent valid pre-Wave-1 arrangement of Foundations, installed specialists, and upgrades for its Loadout. A retry may restore that Opening Plan using the same starting Field Credits, but it never automates between-wave actions. Multiple named plan slots are deferred until testing demonstrates a need.
