# Navigate themed Worlds through authored node maps

The Campaign will use a space-framed Galaxy Map leading into a distinct illustrated World Map for each destination. World One is a biomechanical-industrial frontier; later destinations may use alien grasslands, crystalline moons, ruined orbital structures, void platforms, or other strong local identities. Shared player technology, interface language, and a command craft or rover provide continuity.

World One uses a mostly linear ten-node main path winding across its environment, with the boss at the final main node and the route to World Two visible beyond it. Completion opens the next main node. Only the World Gate checks both boss victory and cumulative Stars. Optional Missions occupy physical side branches, while Mastery remains within its parent Mission Node rather than doubling the map's node count.

The player may pan the World Map and select any unlocked node. A short, skippable command-craft or rover animation travels along revealed connections, and the camera follows newly opened routes after victory. The six-month Vertical Slice fully realizes World One while the Galaxy Map may show future destinations only as clearly locked or distant locations.
