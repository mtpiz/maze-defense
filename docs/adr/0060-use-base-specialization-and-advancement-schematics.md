# Use base, Specialization, and Advancement Schematics

A base Tower Blueprint unlocks its shared Level 1 form, Level 2 requires only Research, and each Level 3 branch requires its own separately collectible Specialization Schematic plus Research. Family-wide Advancement Schematics and Research then open Levels 4 and 5 for every branch the player owns without granting a missing Specialization. This preserves a useful common tower, monetizes meaningful branch choice, and avoids six separate high-level Schematic tracks per family.
