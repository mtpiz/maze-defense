# Use long uniform between-wave planning

Every completed wave will be followed by a fifteen-to-twenty-second planning interval in which the player may revise Foundations, Dismantle, and Refit before the next wave launches automatically. Early Launch ends the interval and awards additional Field Credits. There will be no separate Rebuild Window; preparation is a substantial, consistent part of every wave rather than a rare exception. This supersedes ADR-0028's four-to-six-second interval.
