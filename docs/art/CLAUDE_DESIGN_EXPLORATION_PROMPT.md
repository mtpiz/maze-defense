# Claude Design — Independent Exploration Prompt

Status: Prepared for post-Core-Combat-Gate visual exploration; not a production-style approval.

Use this as a new Claude Design project without uploading the current game, existing concept images,
or a design system. It is intentionally neutral so the result is an independent comparison.

```text
Create four substantially different visual directions for a portrait mobile mazing tower-defense game. Begin from a blank visual slate and choose the art style, rendering, palette, typography, iconography, interface, worlds, creatures, and tower language yourself.

Players place inexpensive Foundation towers before and during waves to create a valid ground route through ordered Waypoints. Airborne enemies touch the same Waypoints but ignore towers. Arenas default to a fully visible 9×14 field but may use other shapes and sizes. A loadout contains Foundation plus three permanent specialist Blueprints; each family can develop into two branches. The HUD needs Lives, waves, Field Credits, pause, speed, route feedback, and contextual tower controls.

For each direction show the same Arena in planning and dense combat, a Campaign view with several visually unique Worlds, and a tower collection/Loadout view. Player towers remain coherent futuristic technology across Worlds, with only restrained regional influence.

Present A–D as separate editable canvases at real phone proportions with a one-sentence rationale for each. Keep mechanics identical so only the design direction changes.
```
